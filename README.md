# EED-Villus-Morphometry

An open-source Python toolkit for automated morphometric analysis of duodenal villi and crypts from histopathology images.

## Features

- Read histopathology images
- Automatic tissue detection
- Scale bar calibration
- Villus segmentation
- Crypt detection
- Villus height measurement
- Crypt depth measurement
- Villus:Crypt ratio
- Quality control
- CSV export
